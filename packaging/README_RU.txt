SIRIUS 0.5.1 — Windows 10/11, 64 бита

УСТАНОВКА
1. Запустите Sirius-Setup-0.5.1.exe.
2. Нажмите «Далее», выберите папку установки.
3. Отметьте нужные ярлыки: рабочий стол и меню «Пуск».
4. Нажмите «Установить», затем «Готово».

Python и модель распознавания уже внутри. Нужны около 650 МБ для
программы и примерно 1,5 ГБ свободного места на время установки.
Установка выполняется для текущего пользователя без прав администратора.
Автозапуск с Windows не включается.

ПЕРВОЕ ИСПОЛЬЗОВАНИЕ
Нажмите Alt + M (английская M), нажмите на сферу или скажите «Сириус».
Для голосового пробуждения произнесите имя отдельно и дождитесь «Слушаю».
Напишите или произнесите help / хелп — возможности появятся в чате.
В чате имя Sirius или Сириус также пробуждает помощника.
Без команд через 60 секунд он снова переходит в ожидание имени.

Примеры: «громкость 50», «яркость 50», «открой блокнот»,
«загрузка процессора». Полный список — команда help и COMMANDS.md
в папке _internal установленного приложения.

Если голос не слышен, проверьте выбранный в Windows микрофон и разрешение
на микрофон для классических приложений. Alt + M работает независимо от
распознавания имени. Голос обрабатывается локально, записи не сохраняются.
Качество распознавания зависит от микрофона, расстояния и фонового шума.

ЗАКРЫТИЕ И УДАЛЕНИЕ
Крестик прячет Sirius в трей. Полный выход — через меню значка в трее.
Удаление — Windows → Установленные приложения → Sirius → Удалить.
Настройки и история сохраняются: %LOCALAPPDATA%\Sirius\UserData.
Файлы команд и снимки: %LOCALAPPDATA%\Sirius\Files и Screenshots.

О СБОРКЕ
Это частная сборка Altynbek. Коммерческой цифровой подписи нет,
поэтому Windows может показать предупреждение о неизвестном издателе.
Перед запуском проверяйте источник файла. SHA256SUMS.txt содержит
контрольную сумму установщика; она проверяет целостность, а не издателя.

Приложение исполняет предусмотренные команды, это не свободный AI-чат.
Яркость, мультимедиа и управление окнами зависят от оборудования и программ.
История не зашифрована. Телеметрии, облачного распознавания и автообновлений нет.
Сторонние лицензии находятся в _internal\THIRD_PARTY_NOTICES.md и
_internal\THIRD_PARTY_LICENSES. Интернет для штатного запуска не нужен.
