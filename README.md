# SIRIUS Desktop — Glass & Presence (05.11.2026)

Локальный помощник Windows 10/11 x64: детерминированные команды, десять категорий навыков, Vosk и Qt Quick/QML. Генеративной модели, облачного распознавания, телеметрии и автоматических обновлений нет. Интернет используется только браузером по явной команде пользователя. Приложение не скачивает модель при запуске.

Актуальные результаты этой версии находятся в `../checks/`. Текущая графика, темы и таймер подробно описаны в `UI_FACE.md`. Краткая инструкция и структура поставки — в `../README.md`. Ядро сохранено из SIRIUS Foundation; обновлены компоновка, анимация и упаковка.

## Запуск готового приложения

1. На рабочем столе откройте ярлык **Sirius** с голубой звездой.
2. Ярлык запускает `%LOCALAPPDATA%\Programs\Sirius\Sirius.exe`. Python и зависимости включены в приложение.
3. В проекте также сохранена portable-копия `../app/Sirius.exe`. Она хранит настройки и историю в `../data` благодаря `app/portable.marker`. Установленная копия использует `%LOCALAPPDATA%\Sirius\UserData`. Одновременно запускайте только одну копию.
4. Работа над пакетом для друзей отложена до завершения самого Sirius. Старый установщик не содержит текущих исправлений.

Сборка и установщик не имеют коммерческой цифровой подписи. Автозапуск не регистрируется. Установщик проверяет SHA-256 каждого распакованного файла; удаление сохраняет пользовательские данные.

## Игровой режим CS2

Скажите «Сириус», затем «игровой режим», «режим игры» или «открой каэс два». Sirius запускает Counter-Strike 2 через Steam. Если открыть игру вручную, работающий Sirius тоже увидит её окно.

После появления окна игры Sirius закрывает распознанные пользовательские приложения текущего сеанса, включая программы в трее, и выходит сам. Steam, CS2, ParkControl, NVIDIA и системные службы продолжают работу. Приложение с открытым запросом сохранения останется на экране. После игры Sirius можно снова запустить ярлыком.

## Управление

- **Кнопка чата сверху слева** на Mini открывает и скрывает Chat справа.
- Скрытый чат не занимает место: Mini можно переместить к правому краю экрана. При открытии чата обе панели автоматически помещаются в рабочую область.
- При запуске сфера неподвижна; обычный текст и открытие чата не будят её. В чате для пробуждения отправьте **Сириус** или **Sirius** (регистр не важен). Можно добавить команду после имени.
- **Лицо в центре Mini**, глобальная **Alt+M** (английская M) или локально распознанное слово **«Сириус»** активируют приём команд.
- После активации можно говорить 60 секунд без повторного обращения. После завершения распознанной команды начинается новый 60-секундный период. Неизвестные звуки не продлевают его и не появляются в чате.
- Видимого таймера нет. Голосовой уровень используется только для анимации; сырое аудио на диск не записывается.
- **X на Mini** скрывает приложение в трей, не останавливая ядро. **X на Chat** скрывает только чат.
- Полный выход, показ окон, включение/отключение микрофона и очистка истории доступны в контекстном меню трея.
- В чате **Enter** отправляет команду, **Shift+Enter** добавляет строку. Текст и голос проходят через одно ядро.
- Для запрошенного действия ответьте голосом или в чате. Согласие — **«да», «давай», «го» (Go), «гоу», «ага», «подтверждаю»**. Отказ — **«нет», «не надо», «отмена», «отмени»**. Подтверждение одноразовое, действует в той же сессии 60 секунд и заменяется новой командой.

## Ровно десять навыков

| Категория | Назначение |
|---|---|
| `volume` | Уровень 0–100, шаги ±20/±10, mute/unmute с чтением состояния Windows Audio |
| `brightness` | Уровень и относительные изменения выбранного дисплея с WMI/DDC/CI readback |
| `applications` | Разрешённые приложения: открыть, вывести на передний план, проверить окна, мягко закрыть, перезапустить с подтверждением |
| `windows` | Свернуть, развернуть, восстановить, переключить, активировать известное окно, показать рабочий стол |
| `browser` | HTTP(S) URL, поиск, вкладки, обновление и навигация только для определённого браузера |
| `media` | Отдельные пауза/продолжение, следующий/предыдущий трек и stop через поддерживаемую Windows Media Control сессию |
| `files` | Папка, пустой TXT, открытие, переименование, перемещение, корзина после подтверждения |
| `clipboard` | Наличие текста, установка, копирование выделения, вставка и выделение; содержимое не выводится в историю |
| `screenshot` | Снимок экрана или известного активного окна, уникальное имя и проверка сохранённого изображения |
| `system_monitor` | Реальные CPU/RAM/диск/батарея; температура только при доступном датчике |

**Точный справочник действий и вариантов формулировок генерируется из всех десяти `phrases.json`: см. `COMMANDS.md`.** Это не свободный чат: неизвестная текстовая фраза даёт понятную ошибку, но не запускает оболочку.

Для музыки: «поставь паузу», «пауза», «продолжи», «следующая», «предыдущая» или «назад». Повторная пауза не возобновляет воспроизведение. Sirius выбирает играющий источник, учитывает активное окно при нескольких источниках и запоминает последнее управляемое приложение для продолжения. Результат проверяется по состоянию проигрывателя; названия треков не сохраняются. Для появления медиасессии сначала запустите трек или видео в самом приложении.

В живой проверке от 05.11.2026 подтверждены пауза, продолжение и переходы вперёд/назад Яндекс Музыки и видеоплеера Chrome. При смене видео браузер может пересоздать медиасессию: Sirius ожидает новую сессию того же приложения и проверяет результат. Если выбранный проигрыватель временно пропал, повторная команда не запускает другой стоящий на паузе плеер. Доступность следующего/предыдущего зависит от текущего видео и кнопок, которые приложение предоставляет Windows; недоступная команда не выдаётся за выполненную.

«Открой браузер» запускает браузер с его обычными настройками, без принудительного `about:blank`. Существующий поиск принимает «поищи в интернете …» и «найди в интернете …».

Громче/тише изменяют уровень на 20 процентных пунктов; «ещё громче/тише» — на 10. Для яркости действует аналогичная схема. Числа вне 0–100 ограничиваются этим диапазоном; дробные и некорректные числовые фразы отклоняются. Регистр и `ё` в буквальных именах файлов/тексте буфера не нормализуются. Для путей с пробелами и пар source/destination используйте двойные кавычки, как в справочнике.

## Настройки и приватность

`../data/config.json` создаётся при первом запуске из `config/defaults.json`. Изменяйте его при закрытом приложении. Повреждённый файл не перезаписывается молча: исправьте JSON или переименуйте его для создания нового.

- `voice.enabled`: `false` полностью отключает захват микрофона.
- `voice.device`: `null` — системное устройство по умолчанию; допустим индекс или точное имя sounddevice.
- `voice.model_path`: встроенная `models/ru_vosk` либо явно указанный локальный каталог совместимой модели.
- `voice.active_seconds`: в Foundation фиксировано **60**.
- `voice.min_confidence`: порог принятия команды. Wake-word использует узкую грамматику Vosk; это **не персональная обученная wake-модель**.
- `hotkey.modifiers=1`, `hotkey.key=77`: Alt+M через RegisterHotKey. Допустимые настройки: modifiers 1–15, key 1–254. Перезапустите приложение после правки. При конфликте комбинация не перехватывается; нажмите на сферу или измените настройки.
- `brightness.display`: индекс поддерживаемого дисплея, по умолчанию `0`.
- `files.root` и `files.allowed_roots`: доверенная область. В новых профилях это `%LOCALAPPDATA%\Sirius\Files`; существующие настройки сохраняются.
- `screenshot.directory`: в новых профилях `%LOCALAPPDATA%\Sirius\Screenshots`.
- `history.enabled=false`: нет записи SQLite; текущие сообщения остаются только в памяти приложения.
- `history.retention_days`: срок хранения 1–3650 дней, по умолчанию 30; дополнительно ограничен объём истории.
- `browser.search_url`: явный HTTPS-шаблон с `{query}`.

SQLite **не зашифрована**. `storage/vault.py` описывает расширяемую границу будущего Vault, но не выдает её за реализованную криптографию. Обычная история не содержит PCM и содержимого буфера. В событиях/истории также скрываются URL, поисковые запросы и содержимое нераспознанных текстовых команд; оригиналы передаются исполнителю только в памяти. Чувствительные данные не следует вставлять в имена файлов или приложений, которые служат объектами команд. Диагностический журнал хранит категории ошибок, а не произвольные команды/документы/секреты.

### Регистрация приложений

Голос и чат используют один Intent Router. Навык `applications` принимает `open_app`, `close_app`, `focus_app`, а также прежние команды проверки состояния и перезапуска. Например, «открой стиим», «переключись на Telegram» и «закрой его». Для закрытия и перезапуска Sirius запрашивает подтверждение. Приложение может свернуться в трей после закрытия окна.

В реестре есть блокнот, калькулятор, проводник, браузер, Steam, Telegram и YouTube. Steam определяется по путям клиента и его оконного процесса. Для Telegram сначала проверяется Telegram Desktop в профиле пользователя, затем установленный пакет Unigram. «Открой ютуб» запускает сайт в браузере по умолчанию. Переключение и закрытие YouTube доступны, когда сайт выбран в одном из окон и Windows позволяет проверить адрес документа и идентификатор вкладки.

Чтобы добавить программу, внесите запись в раздел `applications` существующего `config.json`, подставьте реальный путь к EXE и перезапустите Sirius.

```json
"applications": {
  "editor": {
    "command": ["C:\\Tools\\Editor\\editor.exe"],
    "process_names": ["editor.exe"],
    "aliases": ["редактор"]
  }
}
```

После этого доступны «открой редактор», «переключись на редактор» и «закрой редактор». Алиасы сопоставляются целиком без учёта регистра. Путь и аргументы запуска берутся только из регистрации, а для пользовательского EXE проверяется полный путь процесса. Для установленной копии настройки находятся в `%LOCALAPPDATA%\Sirius\UserData\config.json`.

### Ограничения Windows-интеграции

- `success`/галочка означают подтверждённое постусловие. `unsupported` означает отсутствие поддерживаемого устройства/приложения/наблюдаемого результата. Отправка клавиши сама по себе не считается успехом.
- Яркость зависит от дисплея и драйвера; температура может не предоставляться Windows.
- Браузерные и clipboard-команды зависят от доступности нативного управления/автоматизации и корректно определённого окна. Повышенные приложения могут отклонять ввод обычного процесса.
- Медиа-команды требуют совместимую активную сессию GSMTC. Универсальная перемотка не обещается.
- Закрытие приложения мягкое: диалог несохранённого документа может оставить окно открытым. Принудительного kill нет.
- Перезапись существующих файлов, безвозвратное удаление, UNC/device paths, NTFS ADS и операции через junction/symlink в этой версии запрещены. Выход из доверенных каталогов и перенос между ними требуют подтверждения.
- «Закрой его» разрешается только при известном контексте. Неопределённое окно не заменяется случайным Alt+F4.

## Запуск из исходников

Нужен Python **3.12 x64** (проверяемая версия окружения зафиксирована в отчёте). Зависимости закреплены точными версиями в `requirements.txt`.

```bat
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
start.bat
```

`start.bat` умеет создать `.venv` через `py -3.12` и установить зависимости при её отсутствии. Сеть нужна только на этапе установки, не при штатной работе. Для уже подготовленного другого окружения можно указать `SIRIUS_PYTHON` с абсолютным путём к его python.exe.

Диагностика без записи звука:

```bat
.venv\Scripts\python.exe main.py --diagnose --report docs\diagnose.json
.venv\Scripts\python.exe main.py --text "загрузка процессора" --report docs\cpu.json
.venv\Scripts\python.exe main.py --no-voice
```

Параметр `--data-dir` создаёт отдельный профиль для тестов, не затрагивая рабочую историю. `--voice-probe <каталог>` проверяет модель на **SAPI-синтезированном WAV-файле**, без микрофона и динамиков; это не замена акустическому тесту живой речи.

## Сборка и проверки

```bat
build_exe.bat
```

Скрипт `scripts/build_desktop.ps1` компилирует GPU-шейдер, выполняет PyInstaller в очищенном окружении и собирает EXE запуска с иконкой. Результат: **`../app/Sirius.exe`**. Флаг `-SkipShortcut` сохраняет существующий ярлык установленного приложения. Сборка должна выполняться на Windows x64. Правка исходников требует новой сборки и повторной проверки именно нового EXE.

```bat
.venv\Scripts\python.exe -m pytest tests -q --tb=short
.venv\Scripts\python.exe -m ruff check core security storage skills voice ui main.py scripts tests
.venv\Scripts\python.exe main.py --data-dir .qa\source --no-voice --smoke-output .qa\source-smoke
..\app\Sirius.exe --data-dir .qa\frozen --no-voice --smoke-output .qa\frozen-smoke
```

Аппаратные тесты изменения громкости/яркости являются отдельным явным запуском `scripts/hardware_probe.py --volume --brightness`; исходные состояния восстанавливаются и повторно читаются. Unit-тесты используют mock только на границе Windows API. В production mock-адаптеров нет.

## Архитектура и сохранение старого проекта

```
voice/text → Command → IntentRouter → PermissionPolicy → один из 10 Handler
                                                   → native readback → Result
                                                   → Qt events → SQLite/Chat
```

Windows-операции исполняет один последовательный worker; захват и Vosk работают отдельно. QML не выполняет STT/Windows-вызовы. Две панели используют единый коэффициент DPI/рабочей области, сохраняют ширину 1:2 и общую высоту.

Оригинальные версии Sirius не модифицируются. У новой версии отдельные исходники, настройки и SQLite. История старых версий не импортируется автоматически.

Лицензии компонентов: `THIRD_PARTY_NOTICES.md`, `THIRD_PARTY_LICENSES/`. Компактная геометрия — 180×284 и 360×284 логических пикселей, зазор 8. В меню трея доступны 100%, 125% и 150%. Референсы — два скриншота пользователя от 04.11.2026. Иллюстративная история с референса не добавляется в приложение.


## Живое лицо и стекло

См. `UI_FACE.md`: единственное чёрное стекло (dark), без переключателя, исправленные границы глаз и улыбки, лицо уменьшено и центрировано, орбитальные точки сглажены. `ui/presence.py` следует голосовому FSM, а без голосовой активности использует 60-секундный монотонный таймер. После закрытия лица кадры останавливаются до явной активации.

Проверка настоящей сборки: `..\app\Sirius.exe --face-check-output ..\checks\face-check --data-dir ..\checks\isolated-profile`. Она занимает около 80 секунд, не включает микрофон, проверяет чёрное стекло, отсутствие движения до обращения, оба написания имени и реальный таймер.

## Справка в чате

Напишите `help` или после Alt+M/«Сириус» скажите «хелп»/«помощь». Список с примерами открывается в чате и прокручивается. Старые темы blue/clear мигрируют в dark. Подсказка при пустой истории содержит Alt+M, голосовое обращение и help. Проверка готового UI: `--help-check-output <папка> --data-dir <тестовый профиль>`. Текущие результаты — `../checks/HELP_RESULT.md`.

## GitHub: исходники и локальный Sirius

В репозитории хранится актуальный исходный код `Sirius Desktop/source`. На рабочем столе ярлык `Sirius` запускает установленную сборку `Sirius.exe`, а копия `Sirius Desktop/app/Sirius.exe` соответствует этой установленной сборке.

В Git не входят виртуальное окружение `.venv`, локальная модель Vosk `models/ru_vosk`, личные данные, логи и готовые `.exe`. Для работы из исходников необходимо установить зависимости `requirements.txt` и предоставить совместимую локальную модель Vosk по пути `models/ru_vosk` или указать `voice.model_path`.

Важно: изменение исходников в PyCharm само по себе не изменяет установленный `Sirius.exe`. После правок требуется новая сборка и обновление установленного приложения.
